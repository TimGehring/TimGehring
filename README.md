# 🙋🏻‍♂️ About Me

Hi, I'm Tim! I'm an apprentice Fachinformatiker (application development), and outside of that I build independent software projects across web, desktop, and mobile/macOS.

I'm part of **SPOONI Development**, a RedM resource studio where we build scripts and maps on the CFX Marketplace. Alongside that I maintain a handful of my own projects — a multi-tenant SaaS platform for sports clubs, a macOS vinyl-collection app, a Tauri desktop launcher, and a Go CLI tool — each one a chance to dig deeper into a different part of the stack.

<br>

## 🚀 Projects

- **myTennis** — Multi-tenant SaaS platform for sports clubs, with a full booking system, Stripe billing & Stripe Connect, guest payments, and membership fees. Built on Nuxt 4, Supabase, and Cloudflare, with an extensive pgTAP test suite.
- **SPOONI Development Website** — The studio's public site and storefront, migrating from VitePress to Nuxt 4, integrated with Supabase and the Tebex Headless API.
- **RedM Launcher** — A desktop launcher for RedM built with Tauri 2/Rust and React/TypeScript, with an auto-updating release pipeline via GitHub Actions.
- **myVinyls** — A native macOS app for managing a vinyl collection, built with Swift and SwiftData, integrated with the Discogs API.
- **myConverter** — A Go CLI tool for batch-converting images and videos between formats, built with Cobra and a goroutine worker pool.
- **TC Niedernhausen Website** — Rebuild of a tennis club's website using Nuxt 4 (SSG), Nuxt Content, and Tailwind.
